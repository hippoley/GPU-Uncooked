The real idea: Roofline

Performance has two ceilings: available computation and data movement. The simplified Roofline equation is:

attainable performance ≤ min(peak compute, arithmetic intensity × memory bandwidth)

This restaurant model illustrates a capacity bottleneck, not the full Roofline equation. Real kernels also encounter latency, caching, instruction dependencies, occupancy, launch overhead and numerical constraints.
