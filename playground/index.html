The real idea: Roofline

Performance has two ceilings: computation and data movement. A simplified Roofline model states:

attainable performance ≤ min(peak compute, arithmetic intensity × memory bandwidth)

Our kitchen is only a capacity analogy. Actual GPU kernels involve latency, caching, dependencies, occupancy and launch overhead.
